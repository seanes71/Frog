# Frog Match Battle 3D — Godot 4

This is a **separate** Godot 4 3D prototype, leaving the 2D prototype and all existing web games untouched.

Import `project.godot` from this folder using Godot Project Manager. Run with F5.

Features in source: stationary 7×7 3D board, glossy sphere pieces, directional lighting, tweened swaps, match removal, score goal 350, limit 20 moves, tap and swipe input.

**Status:** Source prototype only. Not yet run-tested or exported to web/iPhone. Natural falling animation, custom 3D art, frog powers, progression, AI battles, and device QA are not implemented.
