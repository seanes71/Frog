# Frog Match Battle — Godot 4

Separate Godot 4 prototype. Open project.godot in Godot 4.2+ on Windows.

Features: 7×7 match-3 board, animated swaps, pop effects, target 350 points, 20 moves, mobile tap/swipe input. The board container is fixed; tiles animate independently.

Status: Source files committed, not yet run-tested or exported to web. Frog powers, full drop animations, saved progress, AI opponent, and polished assets are still future work. Existing HTML games were not modified.
